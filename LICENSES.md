# Лицензии данных и весов

Проверить до демонстрации. Права на веса модели принадлежат провайдеру,
а не тому, кто их скачал (`docs/SETUP.md` §2).

| Источник | Лицензия | Требование |
|---|---|---|
| ECMWF Open Data (IFS / AIFS) | CC-BY-4.0 + ECMWF Terms of Use | указание источника в продукте |
| GFS / NOAA | public domain | нет |
| ERA5 / Copernicus (CDS, ARCO) | Copernicus Licence | указание источника |
| Веса Aurora | лицензия репозитория `microsoft/aurora` | прочитать перед публикацией демо |

## Куда попадает атрибуция

1. Этот файл.
2. Раздел в корневом `README.md`.
3. Футер фронтенда — строка вида:

   > Данные: ECMWF Open Data (CC-BY-4.0), Copernicus ERA5, NOAA GFS.
   > Прогноз рассчитан моделью Aurora (Microsoft).

4. Поле `source` в каждом ответе API (`docs/DATA_CONTRACT.md` §3) — это не
   юридическая атрибуция, но именно оно позволяет пользователю понять,
   чьи данные он видит.
